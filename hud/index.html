Drafts waiting for you. Nothing here has been sent: the fleet reads and prepares, you edit and send. A draft can only leave through the source it came from, so a mail reply cannot be posted to a chat by mistake, and sending twice is refused. One press drafts at most a handful of messages — a mailbox with 2,000 unread emails must not become a 2,000-call bill.

—

Connectivity. Every provider you have wired in, the model the fleet is actually running on, and what that model's envelope has left. A provider shows ready only when its key resolves and the endpoint answered; a model that is missing a driver or a key says so instead of pretending. Model knowledge itself is a signed catalogue, applied only between actions and rollback-able in one command.

Your own accounts. A credential is typed here once and kept in the local vault — encrypted with your Windows account on this machine — and only turns green when the provider itself confirms it. The fleet can read and prepare; anything that sends (mail, a message, a post) waits for you, because a delivered message cannot be recalled. Accounts whose platform requires a business review are listed with that gate quoted instead of an empty promise.

Select an account above to connect it.

The model bench. Each model is added with the limits it is held to — requests and tokens per minute, per day and per week. A reserve is registered and quota-tracked but assigned to nobody until the Control Manager activates it, so spare capacity is known instead of guessed.

Per-model envelopes the Steward manages — rpm / rpd / tpm / tpd. Amber means nearly spent, red means exhausted or cooling down.

Fleet comms. Agents ask each other for help, answer, and hand over files; every message is stored in a thread, and an unanswered request stays visible here until someone answers it.

—

Capability the system wrote for itself. Forged plugins register as first-class actions — no vision, no clicking, no typing.

Live action log — every capability-gated call with its outcome.

Owned processes. Helpers — the WhatsApp sidecar, automation browsers, workers — are supervised: they die with the app, and orphans from a previous run are reconciled at start.

Outcome checks. Each task carries success criteria written before it started, and a separate verifier tests the finished state against them: what was asked, not what the agent claims.

Owner identity. Irreversible work (delete, send, call, install, macro, shell) needs your PIN; a voice match alone never authorises it, because voices can be cloned. Profiles are per OS user, so a shared PC has two owners.

Presence. Two independent senses: voices (how many people are talking, which one is the owner, male/female/unknown) and the camera. The camera needs your stored consent and the OS permission — without both it reports itself off. Frames are never written to disk.

face the core's own dots, drawn as a head with live expression and eye contact
—

Work queued for later. A run that misses its window is skipped with a reason — a machine that slept for eight hours must not wake up and fire the whole backlog at a locked screen.

—

Mistake memory. Every failed action is distilled into a lesson keyed by the kind of failure, and the known fix is attached to the next error of that kind. Counted, never auto-executed.

—

Courtesy to your machine: ZYNTHARO runs below your interactive priority, caps how many workers start at once, and yields during games, calls and presentations. Work you asked for right now is never paused.

Hardware monitor — a deterministic service, not the model. Every number is a real reading from this machine; a sensor that cannot be read says so instead of showing a plausible default.

measuring…

What can physically execute on this machine. Missing drivers are reported, never faked.

Local search over the folders you added. Lexical (FTS5) — no embeddings in this build, and it says so. Every hit is re-checked on disk before it is shown.

Capability Matrix: every tool the system can call, and whether it has been proven on this machine. “provisional” means declared and drivable but never run here — not a claim of working.

The instrument bench. These render the same live state the core does, at a size you can read: load, envelopes, lanes, memory traffic and the dial bank.
